# Exercice 1 — Statuer sur un run

**Actes A1 et A2 — 45 minutes — en binôme**

## Situation

Le run `RUN-2026-03-12` comporte seize échantillons de surveillance respiratoire. Les métriques
sont dans `donnees/qc_run_2026-03-12.csv`. Le prescripteur attend les résultats le soir même pour
deux échantillons, signalés comme urgents dans le fichier.

## Travail demandé

1. Le **run** est-il acceptable ? Citer les indicateurs sur lesquels vous fondez cette décision et
   dire lesquels relèvent du run et lesquels de l'échantillon.
2. Pour chaque échantillon, porter une décision : **accepté**, **rejeté**, ou **à reprendre**, et
   préciser à quelle étape la reprise doit intervenir.
3. Deux échantillons sont urgents. Votre décision change-t-elle ? Justifier.
4. Un échantillon présente un témoin interne d'extraction non détecté alors que ses autres
   métriques sont bonnes. Quelle conclusion, et quelle suite ?
5. Rédiger en trois lignes ce que vous écririez dans le registre pour tracer la décision.

## Ce qui est observé par le formateur

- La distinction entre critère de run et critère d'échantillon est-elle faite explicitement ?
- Le candidat propose-t-il d'abaisser un seuil ? (Si oui, l'exercice n'est pas réussi.)
- L'urgence modifie-t-elle la décision technique, ou seulement la communication ?
- Le témoin interne non détecté est-il traité comme une invalidation de l'échantillon ?
