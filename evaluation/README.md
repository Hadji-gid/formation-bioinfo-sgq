# Évaluation

[`epreuve_theorique.md`](epreuve_theorique.md) est le sujet, distribuable aux participants.

[`grille_correction.csv`](grille_correction.csv) sert au report des points ; il **ne contient pas** les réponses.

Le corrigé (réponses attendues et justifications) n'est **pas** dans ce dépôt : il est détenu par l'animateur sous la référence FM-06-Anx3, document à diffusion restreinte. Publier le corrigé à côté du sujet rendrait l'épreuve sans valeur.
